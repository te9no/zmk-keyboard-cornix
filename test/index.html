1. 機器をつないで調べる

まだ読み取っていません
  1. 左右のキーボードと、まとめ役の機器（MadulaまたはTPS43）の電源を入れます。
  2. まとめ役の機器を、データ通信できるUSBケーブルでパソコンにつなぎます。
  3. 下のボタンを押し、表示された一覧から機器を選びます。15秒ほど待つと結果が出ます。

読み取るだけなので、機器の設定は消えません。

うまく読み取れないとき

ChromeまたはEdgeでこのページを開いてください。機器が一覧に出ないときは、USBケーブルと電源を確認してください。

一覧に複数の候補がある場合、必要なのは記録を読むための接続先です。キーの設定に使う「Studio」の接続先とは別です。どれか分からなければ、ほかの機器を試さず、製作者やサポートに確認してください。

記録を読む別のアプリを開いている場合は、その読み取りを止めてから試してください。文字が出ないだけでは、故障とは判断できません。

保存した記録で調べる・お試し画面を見る

保存した記録から分かるのは、その記録を取ったときの状態です。

3. 設定を消して、最初からつなぎ直す

まず電源とパソコンのBluetoothがオンか確認し、機器を近くに置いて試してください。それでもつながらない場合や、登録を解除するキー操作が分からない場合は、ここからやり直せます。

お使いの機器と、困っていることを選んでください。選ぶだけで設定が変わることはありません。

    間違えないよう、ファイル名を1文字ずつ確認してください

    詳しい人と一緒に確認する情報

      4. 製作者に送る相談文を作る

      機器・診断結果・試したことを、送れる文章にまとめます。自動で送信されることはありません。

      すでに試したこと（当てはまるものだけ）

      機器の種類と接続相手は、上の「設定を消して、最初からつなぎ直す」で選んだ内容を使います。分からなければ未選択のままで大丈夫です。

      作成した時点の内容です。診断し直したり回答を変えたりした場合は、もう一度「相談文を作る」を押してください。名前など、送りたくない情報がないか確認してください。

      詳しい記録を頼まれた場合

      下のボタンで元の記録も保存できます。機器を識別する番号が含まれるため、相談する相手にだけ渡してください。

      詳しい情報（通常は開かなくて大丈夫です）

      左右のアドレスを照合する

      既知のBLEアドレスを入力します。接続順からは左右を推定できません。

      無線リンクの内訳

      local_roleは接続ごとのBLE roleです。ZMKのCentral／Peripheralとは異なります。security=L2以上でも入力到達は未確認です。

      接続相手local_role状態security

      直近のエラー・切断記録

      記録がありません

      Web Serialで115200 baud、DTRを有効化して受信します。送信・1200 baudリセット・bond消去は行いません。

      「まだ確認できません」は「故障」という意味ではありません。
